================================================================================
PUSHGATEWAY 2.0 — SCALING MODEL (4 Components Only)
================================================================================

Only 4 components push to Pushgateway:
  DRHPC, Active Healthcheck, Go Plugin, Pod Node Mapper
(AMD GPU, DCGM, Node Exporter use Prometheus scrape — excluded.)

================================================================================
NODE-SCALED (2 jobs × N nodes)
================================================================================

┌─────────────────────────────┬────────────────┬─────────────────────────────┐
│ Job                         │ Pushes per 60s │ Deployed As                 │
├─────────────────────────────┼────────────────┼─────────────────────────────┤
│ oci_lens_drhpc_metrics      │ N              │ DaemonSet (GPU nodes)       │
│ oci_lens_node_metrics       │ N              │ DaemonSet (all nodes)       │
└─────────────────────────────┴────────────────┴─────────────────────────────┘

Payload: ~17 KB + ~26 KB = ~43 KB per node per cycle

================================================================================
CLUSTER-LEVEL (constant)
================================================================================

┌─────────────────────────────┬────────────────┬─────────────────────────────┐
│ Job                         │ Pushes per 60s │ Deployed As                 │
├─────────────────────────────┼────────────────┼─────────────────────────────┤
│ oci_lens_pod_metrics        │ 1              │ Deployment (1 replica)      │
│ oci_lens_healthchecks       │ 3              │ Job (parallelism 3)         │
└─────────────────────────────┴────────────────┴─────────────────────────────┘

================================================================================
STRESS TEST CALCULATIONS
================================================================================

Pushes per 60s cycle:  2×N + 4
  (drhpc + lens-node per node, pod-mapper ×1, healthcheck ×3)

Example:
  - 10 nodes  → 24 pushes/min
  - 100 nodes → 204 pushes/min
  - 1000 nodes → 2004 pushes/min

Payload per cycle: ~43 KB × N + ~132 KB
  - 1000 nodes → ~43 MB per cycle
